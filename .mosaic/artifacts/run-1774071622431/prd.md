## Goal
构建一款名为 GTO Idiot 的免费德州扑克 GTO 策略练习器，让中级玩家在六人桌与不同风格 BOT 对战，并通过赛后复盘对比 GTO 最优策略，量化决策偏差以系统性提升牌技。

## Features
- F-001 game-engine: 六人桌无限注德州扑克现金局引擎，支持完整牌局流程（发牌、盲注、翻前/翻后/转牌/河牌四街下注、摊牌/弃牌结算），固定盲注结构，底池计算与边池处理
- F-002 player-actions: 玩家操作系统，支持 Fold、Check、Call、Bet、Raise、All-in 六种行动，包含合法行动校验（最小加注、筹码量约束）和操作确认
- F-003 bot-ai: 五种风格 BOT AI 对手——TAG（紧凶）、LAG（松凶）、Fish（被动松）、Nit（极紧）、Maniac（疯狂激进），通过 VPIP/PFR/AF 等参数差异化行为，每个 BOT 分配随机化的个性名称
- F-004 table-ui: 六人桌牌桌 UI，展示玩家座位、手牌、公共牌、底池大小、各玩家筹码量、当前行动指示、下注滑块/输入框，支持桌面浏览器
- F-005 preflop-solver: 翻前 GTO 策略查找，基于预计算的 169 手牌类 × 6 个位置 × 常见行动序列的策略表（JSON 静态数据），覆盖率 100%
- F-006 postflop-solver: 翻后 GTO 策略求解，常见翻后场景预计算覆盖约 70-80%，非常见场景通过简化 DCFR（Rust→WASM，10 个手牌桶 × 3-4 个下注尺寸）实时求解，多人入池时降级为伪单挑模型，响应时间 < 5 秒
- F-007 hand-history: 牌局记录系统，每手牌结束后自动将完整牌局数据（手牌、公共牌、各街行动序列、底池变化、结果）存入 IndexedDB，支持按时间/结果筛选浏览历史
- F-008 hand-review: 赛后复盘系统，逐手回放牌局，在每个决策点并排展示玩家实际操作与 GTO 推荐操作（含各行动的推荐频率），标注偏差程度（符合/轻微偏差/严重偏差），估算 EV 损失
- F-009 session-summary: 对战结果总结，展示本次 session 的盈亏曲线、总手数、关键统计（胜率、摊牌率、弃牌率），以及 GTO 符合度评分（0-100 分）
- F-010 precision-disclaimer: 精度标注系统，在简化求解或伪单挑降级的场景下向用户透明展示"本场景为简化计算，仅供参考"提示

## Constraints
- 前端技术栈限定 React + TypeScript + Tailwind CSS
- 后端技术栈限定 Node.js（承载 WASM 求解器或提供 API）
- 数据持久化仅使用浏览器 IndexedDB，无服务端数据库
- CFR 求解器必须使用 Rust→WASM 路线（纯 JS/TS 实现性能不可行），推荐 fork postflop-solver（MIT 许可）
- 翻后实时求解响应时间 < 5 秒，精度可适当牺牲
- 仅支持六人桌无限注德州扑克现金局，固定盲注结构（如 1/2）
- 6-max 多人翻后场景需降级为伪单挑模型求解，无法提供精确 GTO 解
- 产品需明确标注"仅供学习用途"
- 开源依赖需遵守 MIT 许可，避免 AGPL 许可的库（如 TexasSolver）

## Out of Scope
- 多桌同时游戏
- 锦标赛/SNG 模式
- 用户账号注册/登录系统
- 云端数据同步
- 高精度 Solver（Pluribus 级别精确求解）
- 详细 HUD 统计报表（VPIP/PFR/3Bet/WTSD 等）
- 移动端/响应式适配
- 实时多人在线对战
- 自定义盲注结构
- 手牌范围编辑器
- 积分/排名系统
