## Goal
构建一款名为 GTO Idiot 的纯前端德州扑克 GTO 策略练习器，让玩家在 6 人桌与 BOT 实战对战中学习 GTO 策略，并通过赛后逐手复盘对比 GTO 最优解来系统性提升决策水平。

## Features

- F-001 poker-engine: 德州扑克游戏引擎——实现完整的 6-max 牌局逻辑，包括洗牌发牌（Fisher-Yates）、盲注发放（固定 1/2）、起始筹码 100BB、四轮下注管理（Preflop → Flop → Turn → River）、底池计算（主池/边池）、摊牌比较（使用 pokersolver 或 phe 库进行牌力评估）、座位与庄位轮转。支持 1 名真人玩家 + 5 个 BOT。
- F-002 player-actions: 玩家操作系统——真人玩家可执行标准操作：Fold / Check / Call / Bet / Raise / All-in。操作需遵守规则约束（如不能在有人下注时 Check，Raise 至少为上次加注的 2 倍等）。操作面板需实时显示当前可用操作及对应金额。
- F-003 gto-bot-engine: 近似 GTO 规则引擎驱动的 BOT——5 个 BOT 基于近似 GTO 规则自动决策。Preflop 阶段：按位置（UTG/HJ/CO/BTN/SB/BB）使用预设的 100bb/2.5bb open 范围表（RFI/3-bet/call/fold）。Postflop 阶段：基于 SPR（筹码底池比）+ 底池赔率 + 手牌强度的决策树，区分 value bet / bluff / check-call / fold。BOT 行为需加入适当随机化（混合策略）以避免机械化。明确标注为"基于规则的近似 GTO 策略"。
- F-004 table-ui: 牌桌界面——渲染 6 人桌的完整视觉界面，包括：玩家座位（头像/筹码/位置标签）、公共牌区域、底池显示、庄位按钮、当前行动指示器、发牌/翻牌动画。使用 CSS/SVG 渲染 52 张扑克牌。实时显示底池大小、各玩家筹码变化。
- F-005 game-result: 牌局结果展示——每局结束后展示本局结果摘要：赢家及赢取筹码、摊牌时各玩家手牌及牌型、关键手牌亮点（如最大底池、All-in 对决）。显示本次 session 的累计盈亏。
- F-006 data-persistence: 对战数据持久化——使用 IndexedDB 持久化存储所有牌局数据。每局记录包括：每个决策点的完整状态（公共牌、底池、有效筹码、位置、行动序列）、最终结果（赢家/输赢金额）、时间戳。支持数千局记录的存储和高效检索。
- F-007 hand-replay: 赛后逐手复盘——提供逐手回放功能，用户可步进/回退浏览牌局每个决策点。在每个决策点同时展示：「你的实际选择」vs「GTO 推荐选择」。使用颜色编码标识决策质量（绿色=符合 GTO，黄色=轻微偏差，红色=严重偏差）。附带简要策略解释说明 GTO 推荐的原因。
- F-008 ev-analysis: EV 差值分析——在复盘的每个决策点计算并展示 EV 差值（用户选择的 EV 与 GTO 最优选择的 EV 之差）。EV 基于简化模型计算（手牌胜率 × 底池 - 投入成本）。汇总整局的累计 EV 损失。对低置信度场景（如复杂多人底池）标注提示，建议用户参考专业工具。
- F-009 history-list: 历史对战记录——展示所有历史牌局列表，按时间倒序排列。每条记录显示：日期时间、盈亏金额、关键手牌数量。支持点击进入任意历史牌局的复盘模式。支持按日期范围筛选。
- F-010 session-management: 对战 Session 管理——支持开始新 session（重置筹码到 100BB）、在 session 内连续打多局、暂停/恢复 session。显示当前 session 的局数和累计盈亏统计。

## Constraints
- 纯前端应用（React + TypeScript + Tailwind CSS），无后端服务器，所有计算在浏览器端完成
- 数据存储使用 IndexedDB，不依赖任何远程服务
- GTO 策略为基于规则的近似实现（预设范围表 + 位置/SPR/底池赔率决策树），非 solver 精确计算；产品内需明确标注"近似 GTO"
- 固定盲注结构 1/2，起始筹码 100BB（200 chips），不支持自定义
- 仅支持 6-max（六人桌），不支持其他桌型
- 牌力评估使用成熟的开源库（pokersolver 或 phe），不自行实现
- EV 计算采用简化模型，需在复杂场景标注置信度
- 前端性能要求：牌力评估和 BOT 决策需在 200ms 内完成，保证 UI 流畅

## Out of Scope
- 多人在线对战（实时联网多人游戏）
- 锦标赛（MTT）/ Sit & Go（SNG）模式
- 自定义盲注结构或起始筹码深度
- Solver 级精确 GTO 计算（如 PioSolver/WASM Postflop 级别的求解）
- 排行榜、社交功能、用户账号系统
- 移动端原生应用适配（仅桌面浏览器优先）
- 手牌历史文件导入/导出（如 PokerStars hand history 格式）
- 多桌同时游戏
- BOT 难度/风格自定义
- 国际化 / 多语言支持
