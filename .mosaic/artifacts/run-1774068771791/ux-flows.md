## User Journeys

### Flow 1: App Navigation & Landing (app-navigation-flow)
**Covers: F-010**

```
用户打开应用
  → 展示主页/大厅页（顶部导航栏含"GTO Idiot"品牌名 + 页面切换链接）
  → 主页展示三个核心入口：
      ├── [开始新牌局] → 跳转牌桌页
      ├── [历史记录] → 跳转复盘/统计页（历史列表Tab）
      └── [统计概览卡片] → 跳转复盘/统计页（统计面板Tab）
  → 顶部导航栏始终可见，支持在三个页面间切换：主页 / 牌桌 / 复盘与统计
```

### Flow 2: Game Session — 完整牌局对战流程 (game-session-flow)
**Covers: F-001, F-002, F-003, F-004, F-005, F-006, F-007**

```
用户点击[开始新牌局]
  → 进入牌桌页，初始化六人桌（1人类 + 5 BOT，各200BB，盲注1/2）
  → 系统分配初始位置（用户随机座位），dealer button 标记
  → 开始第一手牌：
      Step 1: 发牌阶段
        → Fisher-Yates洗牌 → 每人发2张底牌
        → 用户手牌正面展示，BOT手牌背面
        → SB/BB自动下盲注，底池更新
      Step 2: Preflop行动轮
        → 按位置顺序（UTG→MP→CO→BTN→SB→BB）行动
        → 当前行动玩家高亮
        → BOT回合：BOT根据位置+手牌查GTO策略表决策（含混合策略随机）→ 动画展示动作 → 自动进入下一位
        → 用户回合：展示动作按钮区（fold/check/call/raise滑块/all-in）→ 用户选择动作 → 确认执行
        → 底池实时更新
        → 所有人行动完毕或仅剩一人 → 进入下一阶段
      Step 3: Flop（翻牌）
        → 发3张公共牌，展示在公共牌区域
        → 街道标识更新为"Flop"
        → 重复行动轮（从SB/第一个存活位置开始）
      Step 4: Turn（转牌）
        → 发第4张公共牌 → 行动轮
      Step 5: River（河牌）
        → 发第5张公共牌 → 行动轮
      Step 6: 摊牌/结算
        → 若多人存活：翻开所有存活玩家手牌
        → 7张牌最佳5张牌型评估 → 判定胜负
        → 展示赢家高亮 + 牌型名称 + 赢得筹码数
        → 处理side pot（如有all-in情况）
        → 底池分配动画
      Step 7: 记录 & 继续
        → 完整手牌数据写入localStorage
        → 展示[立即复盘]和[继续下一手]按钮
        → dealer button顺移，位置轮转
        → 下一手牌从Step 1开始
  → 用户可随时通过导航栏离开牌桌
```

### Flow 3: Hand Review — 逐手复盘流程 (hand-review-flow)
**Covers: F-008, F-005, F-007**

```
入口A：牌局结束后点击[立即复盘]
入口B：从历史记录列表点击某手牌
  → 进入复盘界面
  → 展示手牌概要卡片（手牌ID、日期、用户位置、起手牌、最终结果盈亏）
  → 时间线导航条：Preflop → Flop → Turn → River → Showdown
  → 用户点击/自动播放每条街：
      → 展示当前街的牌面状态（公共牌）
      → 展示底池大小
      → 逐个展示每位玩家的动作（含下注金额）
      → 在用户决策点：
          ├── 左侧：「用户实际动作」（如 raise to 6）
          ├── 右侧：「GTO推荐动作分布」（如 raise 50% / call 25% / fold 25%）
          └── 颜色标注偏离程度：
              🟢 绿色 = 符合GTO（用户动作在GTO推荐的最高频率动作中）
              🟡 黄色 = 轻微偏离（用户动作在GTO推荐中但非最优）
              🔴 红色 = 严重偏离（用户动作在GTO推荐中频率为0或极低）
  → 底部展示整手牌的GTO符合度评分
  → [上一手] [下一手] 导航按钮
```

### Flow 4: Session Stats — 统计分析流程 (session-stats-flow)
**Covers: F-009, F-007**

```
用户进入复盘/统计页 → 选择"统计面板"Tab
  → 从localStorage聚合计算所有历史数据
  → 展示统计面板：
      Section 1: 总览指标卡片
        → 总手数 | 总盈亏 | 每手平均盈亏 | GTO符合率
      Section 2: 核心指标
        → VPIP（主动入池率）| PFR（翻前加注率）| AF（攻击频率）
      Section 3: 按位置分析
        → 6个位置（UTG/MP/CO/BTN/SB/BB）的胜率和GTO符合率分布（柱状图/表格）
      Section 4: 按牌力分析
        → 不同起手牌强度分类的决策质量分布
  → 数据实时刷新（每次进入页面重新聚合）
```

### Flow 5: History Browse — 历史记录浏览流程 (history-browse-flow)
**Covers: F-007, F-010**

```
用户进入复盘/统计页 → 默认展示"历史记录"Tab
  → 展示手牌列表（按时间倒序）
      每行：手牌ID | 日期时间 | 用户位置 | 起手牌 | 结果（+/- 筹码）| GTO符合度
  → 支持滚动加载更多
  → 点击任一手牌 → 进入Flow 3（逐手复盘）
  → 存储容量管理：超出2000手时自动删除最早记录（静默处理）
```

## Interaction Rules

### 表单与输入
- **Raise滑块**：最小值为当前最小加注额，最大值为玩家剩余筹码（all-in）；滑块拖动时实时显示金额数值；支持直接输入金额
- **动作按钮**：仅展示当前合法动作（如不能check时不显示check按钮）；按钮尺寸足够大，防止误操作
- **动作确认**：fold和all-in需二次确认弹窗（"确定要fold吗？"/"确定All-in吗？"），其他动作单击直接执行

### 加载与等待状态
- **BOT思考**：BOT决策时显示该玩家座位上的思考动画（0.8-1.5秒随机延迟），模拟真实对局节奏
- **发牌动画**：底牌发牌和公共牌翻牌有简短动画（0.3秒/张）
- **筹码变动动画**：下注和底池收集有筹码移动动画（0.5秒）
- **数据加载**：历史记录和统计面板首次加载时显示骨架屏（skeleton），数据就绪后渐入

### 错误与边界处理
- **localStorage容量不足**：检测写入失败时提示"存储空间不足，已自动清理最早的100手记录"
- **牌局中离开**：用户通过导航离开牌桌时弹窗确认"当前牌局进行中，离开将丢失本手进度，确定离开？"
- **空状态**：历史记录为空时展示引导插画 + "还没有对局记录，开始你的第一手牌吧！" + [开始牌局]按钮
- **统计空状态**：不足10手时提示"至少完成10手牌后才能生成有意义的统计数据"

### 复盘交互
- **街道切换**：时间线导航条可点击任意街道直接跳转，也可线性播放
- **GTO对比展示**：偏离程度颜色编码始终一致（🟢🟡🔴），附带文字说明
- **上下手切换**：复盘界面支持[上一手][下一手]快速切换，无需返回列表

### 全局交互规则
- **响应式布局**：桌面端优先，最小支持宽度1024px
- **中文界面**：所有UI文案使用中文，扑克术语保留英文（fold/call/raise/flop/turn/river等）
- **简化GTO标注**：所有GTO相关展示区域标注"简化GTO参考"水印/角标，明确非精确求解器结果
- **导航状态**：顶部导航栏高亮当前页面，牌桌进行中时导航栏"牌桌"项显示脉动指示器

## Component Inventory

### 导航与布局组件
- **AppShell**: 应用顶层布局容器，包含TopNav和页面内容区域，管理路由状态
- **TopNav**: 顶部导航栏，展示"GTO Idiot"品牌名和三个页面切换链接（主页/牌桌/复盘与统计），高亮当前页面，牌桌进行中时显示脉动指示器
- **PageContainer**: 页面内容容器，统一内边距和最大宽度

### 主页组件
- **LobbyPage**: 主页/大厅页，组合统计概览卡片和核心入口按钮
- **QuickStatsCard**: 主页统计概览卡片，展示总手数/总盈亏/GTO符合率的快照数据
- **StartGameButton**: 醒目的"开始新牌局"主操作按钮

### 牌桌组件
- **GameTablePage**: 牌桌页面容器，管理牌局状态机和组件编排
- **PokerTable**: 六人桌可视化核心组件，椭圆形桌面布局，管理6个座位位置排列
- **PlayerSeat**: 单个玩家座位组件，展示头像/名称、筹码量、当前下注额、dealer/SB/BB标记、手牌区域、行动状态（思考中/已fold/已all-in），当前行动玩家高亮边框
- **CardDisplay**: 扑克牌展示组件，支持正面（花色+点数）和背面两种状态，支持翻牌动画
- **CommunityCards**: 公共牌区域组件，展示0-5张公共牌，支持逐张翻牌动画
- **PotDisplay**: 底池金额展示组件，含主池和边池，筹码移动动画
- **ActionPanel**: 用户动作操作面板，包含fold/check/call/raise/all-in按钮，仅展示当前合法动作
- **RaiseSlider**: 加注金额选择器，滑块+数值输入框组合，标注最小/最大值
- **ConfirmDialog**: 二次确认弹窗组件，用于fold和all-in的确认
- **StreetIndicator**: 当前下注轮次标识组件（Preflop/Flop/Turn/River）
- **HandResultOverlay**: 单手牌结算浮层，展示赢家、牌型、赢得筹码，提供[立即复盘]和[继续下一手]按钮
- **LeaveGameDialog**: 离开牌桌确认弹窗

### 复盘组件
- **ReviewPage**: 复盘/统计页面容器，管理Tab切换（历史记录/统计面板）
- **HandHistoryList**: 历史手牌列表组件，按时间倒序展示手牌摘要行，支持滚动加载
- **HandHistoryItem**: 单条历史记录行，展示手牌ID、日期、位置、起手牌、盈亏结果、GTO符合度
- **HandReviewPanel**: 逐手复盘主面板，组合时间线导航和决策对比展示
- **HandSummaryCard**: 手牌概要卡片，展示手牌基本信息和最终结果
- **StreetTimeline**: 街道时间线导航条（Preflop→Flop→Turn→River→Showdown），支持点击跳转和线性播放
- **ActionReplayList**: 单条街的动作回放列表，逐个展示每位玩家的动作
- **GTOComparisonCard**: GTO对比卡片，并排展示用户实际动作和GTO推荐动作分布，含偏离程度颜色标注
- **GTOFrequencyBar**: GTO推荐动作频率分布可视化条（如 raise 50% / call 25% / fold 25%）
- **DeviationBadge**: 偏离程度标记组件（绿色/黄色/红色 + 文字标签）
- **HandNavigation**: 上一手/下一手导航按钮组

### 统计组件
- **StatsPanel**: 统计面板主容器，组合各统计区块
- **OverviewMetrics**: 总览指标卡片组（总手数/总盈亏/每手平均盈亏/GTO符合率）
- **CoreMetrics**: 核心玩家指标展示（VPIP/PFR/AF）
- **PositionBreakdown**: 按位置统计分布组件（6个位置的胜率和GTO符合率，柱状图或表格形式）
- **HandStrengthAnalysis**: 按起手牌强度分类的决策质量分布组件

### 通用/共享组件
- **ChipAmount**: 筹码金额展示组件，统一格式化（如"1,200"），支持颜色区分正负
- **EmptyState**: 空状态展示组件，含插画、文案和可选操作按钮
- **SkeletonLoader**: 骨架屏加载占位组件
- **GTOWatermark**: "简化GTO参考"水印/角标组件，用于所有GTO相关展示区域
- **TabSwitcher**: Tab切换组件，用于复盘页的历史记录/统计面板切换
- **Tooltip**: 工具提示组件，用于解释扑克术语和统计指标
