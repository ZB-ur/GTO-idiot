## Goal
构建一个名为"GTO Idiot"的纯浏览器端德州扑克GTO策略练习器，让中级玩家通过6-max现金桌实战对练、牌局复盘和GTO偏差分析，系统性提升GTO执行力。

## Features
- F-001 game-engine: 6-max现金桌牌局引擎 — 完整的Texas Hold'em状态机，包括发牌、盲注、四轮下注（翻前/翻后/转牌/河牌）、底池计算、摊牌和胜负判定。支持标准6-max位置（UTG/HJ/CO/BTN/SB/BB），按钮轮转，固定盲注结构（可配置盲注大小），100BB起始筹码。
- F-002 bot-ai: 可配置BOT对手系统 — 用户选择1-5个BOT对手，每个BOT可独立配置难度级别：鱼（松散被动/随机策略）、常规（基于范围表+位置感知+底池赔率的TAG策略）、GTO（基于CFR近似的均衡策略）。BOT决策需在200ms内完成。
- F-003 preflop-gto: 翻前GTO范围表引擎 — 内置6-max各位置的预计算翻前范围表，覆盖open raise/3-bet/4-bet/call/fold频率。169种起手牌组合×6个位置×主要场景（未开池/面对open/面对3bet）。用于GTO级BOT决策和复盘偏差对比。
- F-004 postflop-gto: 翻后简化CFR求解器 — 浏览器端实时CFR计算引擎，采用简化博弈树（下注尺度限制为33%/66%/100%底池），使用Discounted CFR算法。目标亚秒级响应（<500ms）。输出每个决策点的行动频率分布（fold%/call%/raise%）。用于GTO级BOT翻后决策和复盘偏差分析。
- F-005 gto-hint: 实时GTO提示功能 — 用户在任意决策点可点击"提示"按钮，查看当前局面的GTO建议行动和频率分布（如：fold 35% / call 45% / raise 20%）。提示默认关闭，用户主动触发。显示推荐行动和EV估算。
- F-006 hand-history: 牌局历史记录 — 每手牌自动记录完整数据：所有玩家手牌（摊牌时）、公共牌、每轮行动序列（玩家/动作/金额）、底池变化、最终结果（赢家/输家/金额）。使用IndexedDB存储，支持按时间/结果/位置筛选，单手牌数据~1-2KB JSON。
- F-007 hand-replay: 赛后复盘手牌回放 — 用户浏览历史牌局列表，选择任意一手牌进行逐步回放。回放器支持前进/后退/跳转到特定街，每步显示当时的牌桌状态（玩家手牌、公共牌、底池、筹码）。在每个用户决策点，显示用户实际行动和GTO建议行动的对比。
- F-008 deviation-analysis: GTO偏差标记与分析 — 在复盘中，系统自动标记用户决策与GTO策略的偏差。偏差分为三级：轻微（GTO频率差<15%）、中等（15%-40%）、严重（>40%）。显示偏差描述（如"GTO建议加注66%pot频率为60%，你选择了跟注"）。每个偏差点标注EV损失估算。
- F-009 stats-dashboard: 统计总览面板 — 展示整体对战数据：总手数、胜率、盈亏曲线图（按手数或session）、VPIP/PFR/3Bet等关键指标、最常见的GTO偏差类型TOP5、按位置的盈亏分布。支持时间范围筛选（最近100手/500手/全部）。
- F-010 session-management: 牌局会话管理 — 用户可开始新session（配置BOT数量、各BOT难度、盲注大小）、暂停/继续session、结束session查看本次小结。Session小结包括本次手数、盈亏、关键偏差点回顾。
- F-011 poker-table-ui: 扑克牌桌UI — 可视化牌桌界面：椭圆形牌桌、6个座位（显示玩家名/筹码/手牌/状态）、公共牌区域、底池显示、庄家按钮标记。行动面板（Fold/Call/Raise按钮+加注滑块）。支持深色主题。响应式布局适配桌面浏览器。

## Constraints
- 纯浏览器端运行，无后端服务器，所有计算在客户端完成
- 数据存储使用IndexedDB，无云端同步
- 技术栈限定React + TypeScript + Tailwind CSS
- 仅支持6-max（六人桌）No-Limit Hold'em现金桌
- GTO计算必须亚秒级响应（<500ms），翻后CFR采用简化博弈树（33%/66%/100%底池下注尺度）
- CFR算法在浏览器主线程外运行（Web Worker），避免UI阻塞
- 翻后GTO标注为"近似GTO"而非"精确GTO"，向用户明确说明精度限制
- 单次session数据量控制在合理范围，避免IndexedDB存储膨胀（建议上限10000手牌历史）

## Out of Scope
- 多人在线对战（实时多人联网）
- 锦标赛（MTT/SNG）模式
- 完整精确GTO求解器（PioSOLVER级别精度）
- 用户账号注册/登录系统
- 云端数据同步和跨设备访问
- 移动端原生App或移动端适配优化
- 高级统计分析（按对手类型细分、泄漏分析器、学习路径推荐）
- WebAssembly版CFR求解器（MVP使用纯TypeScript实现，后续可升级）
- 手牌历史导入/导出（PokerStars/GGPoker格式）
- 多语言国际化（MVP仅中文界面）
- Heads-up或其他桌型（仅6-max）
- 自定义下注尺度配置（MVP固定33%/66%/100%）
