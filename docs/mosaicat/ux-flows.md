## User Journeys

### Flow 1: Session Setup & Game Start (新建牌局会话)
**Covers: F-010, F-002, F-011**

1. 用户打开应用 → 显示主页（Dashboard / 开始游戏入口）
2. 点击"开始新牌局" → 弹出 Session 配置面板
3. 配置 BOT 数量（1-5）→ 每个 BOT 独立选择难度（鱼/常规/GTO）
4. 配置盲注大小（如 1/2, 2/5, 5/10）→ 确认所有玩家 100BB 起始筹码
5. 点击"开始" → 进入牌桌 UI，牌局开始发牌

### Flow 2: Core Gameplay Loop (核心对战循环)
**Covers: F-001, F-011, F-005, F-006**

1. 系统自动分配位置（UTG/HJ/CO/BTN/SB/BB），发底牌
2. 翻前下注轮：按位置顺序行动
   - 轮到用户 → 行动面板激活（Fold / Call / Raise + 滑块）
   - 轮到 BOT → BOT 决策动画（200ms 内完成），显示行动结果
3. 用户可在决策点点击"GTO 提示"按钮 → 弹出频率分布浮层（fold% / call% / raise%）
4. 翻牌发出 → 翻后下注轮（同上行动流程）
5. 转牌发出 → 转牌下注轮
6. 河牌发出 → 河牌下注轮
7. 摊牌 → 显示所有存活玩家手牌 → 判定赢家 → 底池分配动画
8. 每手牌自动保存到 IndexedDB → 庄家按钮轮转 → 下一手开始
9. 用户可随时点击"暂停" → 暂停 session；点击"继续" → 恢复
10. 用户点击"结束 Session" → 显示 Session 小结（手数/盈亏/关键偏差点）

### Flow 3: GTO Hint Interaction (GTO 提示交互)
**Covers: F-005, F-003, F-004**

1. 用户在任意决策点看到"💡 提示"按钮（默认不展开）
2. 点击提示按钮 → 系统调用翻前范围表或翻后 CFR 求解器
3. 显示 GTO 建议浮层：
   - 推荐行动频率分布（如 Fold 35% / Call 45% / Raise 20%）
   - 每个行动的 EV 估算
   - 翻后标注"近似 GTO"精度说明
4. 用户阅读后关闭提示 → 做出自己的决策
5. 提示查看状态记录到牌局历史（用于复盘分析是否依赖提示）

### Flow 4: Hand History Browsing (牌局历史浏览)
**Covers: F-006**

1. 用户从主导航进入"牌局历史"页面
2. 显示牌局列表（按时间倒序），每项显示：手牌编号、日期、位置、结果（±BB）、关键标记
3. 用户使用筛选器：按时间范围 / 盈亏结果（赢/输）/ 位置筛选
4. 点击某手牌 → 进入手牌详情 / 回放界面

### Flow 5: Hand Replay & Deviation Review (手牌回放与偏差复盘)
**Covers: F-007, F-008**

1. 用户选择一手牌进入回放模式
2. 回放器显示初始状态：牌桌布局、各玩家筹码、位置
3. 用户点击"下一步" → 逐步重现每个行动（发牌/下注/加注/弃牌）
4. 支持操作：前进 / 后退 / 跳转到特定街（Preflop / Flop / Turn / River）
5. 在用户决策点，回放器自动对比显示：
   - 用户实际行动（高亮标记）
   - GTO 建议行动频率分布
   - 偏差等级标记（🟢轻微 / 🟡中等 / 🔴严重）
   - 偏差描述文本（如"GTO 建议加注 66%pot 频率为 60%，你选择了跟注"）
   - EV 损失估算
6. 用户可逐个查看所有偏差点，或点击"下一个偏差"快速跳转

### Flow 6: Statistics Dashboard (统计面板)
**Covers: F-009**

1. 用户从主导航进入"统计"页面
2. 顶部选择时间范围：最近 100 手 / 500 手 / 全部
3. 总览卡片区：总手数、总体胜率、总盈亏（BB）
4. 盈亏曲线图：按手数绘制盈亏走势折线图
5. 关键指标区：VPIP / PFR / 3Bet% / WTSD% 等数值
6. GTO 偏差 TOP5：最常见的偏差类型排行
7. 位置分布：按 6 个位置的盈亏柱状图
8. 所有数据响应筛选条件实时刷新

## Interaction Rules

### 表单与配置交互
- Session 配置面板使用模态弹窗，所有配置项即时可见，无分步向导
- BOT 数量选择后立即渲染对应数量的难度选择器，无需手动添加
- 盲注大小使用预设选项（1/2, 2/5, 5/10）+ 自定义输入
- 配置不合法时（如 BOT 数量为 0），提交按钮禁用并显示行内提示

### 游戏行动交互
- 行动面板仅在轮到用户时激活，其他时间灰化禁用
- Fold / Call 为一键操作；Raise 需配合滑块或输入框指定金额
- 加注滑块范围：最小加注 → 全下（All-in），预设快捷按钮（33% / 66% / 100% 底池）
- 行动确认后立即执行，无二次确认弹窗（节奏感优先）
- BOT 行动使用短暂延迟动画（200-500ms）模拟思考过程

### GTO 提示交互
- 提示按钮固定在行动面板上方，仅用户决策时可点击
- 提示浮层不阻塞行动面板，用户可边看提示边操作
- 翻后提示首次展示时显示"近似 GTO"免责说明（仅首次）
- 提示浮层支持点击外部或关闭按钮关闭

### 加载与等待状态
- CFR 计算使用 Web Worker，UI 保持响应
- GTO 提示计算中显示旋转加载指示器（预计 <500ms）
- 牌局历史列表使用虚拟滚动（10000 手历史场景）
- 初始数据从 IndexedDB 加载时显示骨架屏

### 错误处理
- IndexedDB 存储失败 → 顶部 Toast 提示"保存失败，请检查浏览器存储空间"
- CFR 计算超时（>2s） → 降级显示简化建议 + "计算超时，结果可能不够精确"
- Session 异常中断（页面关闭） → 下次打开自动检测未完成 session → 提示"恢复上次牌局？"

### 回放器交互
- 回放使用步进控制（非自动播放），保证用户完全掌控节奏
- 前进/后退按钮 + 键盘快捷键（← →）支持
- 街跳转使用顶部时间轴标签（Preflop | Flop | Turn | River）
- 偏差点在时间轴上用彩色圆点标记，可直接点击跳转
- 偏差详情使用侧边抽屉或内联展开，不遮挡牌桌视图

### 统计图表交互
- 盈亏曲线图支持 hover 查看具体手数和盈亏值（Tooltip）
- 筛选条件切换时图表平滑过渡动画（200ms）
- 图表数据点可点击跳转到对应牌局历史

### 通用规则
- 全局使用深色主题（扑克应用标准风格）
- 所有操作反馈 <100ms 触觉响应（按钮状态变化）
- 页面间导航使用侧边栏或顶部 Tab，保持上下文不丢失
- 数据变更自动保存，无需手动保存按钮
- 中文界面，所有文案使用简体中文

## Component Inventory

### 页面级组件
- **AppShell**: 应用外壳，包含顶部导航栏、侧边栏导航、主内容区域。管理全局路由和深色主题。
- **HomePage**: 首页/仪表盘，展示快速开始入口、最近 session 概览、关键统计摘要。
- **GamePage**: 游戏页面，承载牌桌 UI 和行动面板，管理当前 session 的游戏状态。
- **HistoryPage**: 牌局历史列表页，展示所有历史牌局记录，提供筛选和搜索功能。
- **ReplayPage**: 手牌回放页，承载回放器和偏差分析面板。
- **StatsPage**: 统计面板页，展示图表和数据指标。

### 牌桌与游戏组件
- **PokerTable**: 椭圆形牌桌主组件，布局 6 个座位、公共牌区域、底池显示区域。
- **PlayerSeat**: 单个座位组件，显示玩家名称、筹码数、手牌（正面/背面）、当前状态（行动中/弃牌/全下）、庄家按钮标记。
- **CardDisplay**: 扑克牌显示组件，支持正面（花色+点数）和背面渲染，支持翻牌动画。
- **CommunityCards**: 公共牌区域组件，依次展示 Flop(3) / Turn(1) / River(1)。
- **PotDisplay**: 底池金额显示组件，支持主池和边池分别显示。
- **DealerButton**: 庄家按钮标记组件，定位在对应座位旁。
- **ActionPanel**: 行动操作面板，包含 Fold/Call/Raise 按钮和加注控制器。仅用户回合时激活。
- **RaiseSlider**: 加注金额滑块组件，含最小/最大范围、预设快捷金额按钮（33%/66%/100% pot）、手动输入框。
- **BotActionIndicator**: BOT 行动动画指示器，显示 BOT 思考中和决策结果的过渡动画。

### GTO 提示组件
- **HintButton**: GTO 提示触发按钮，固定于行动面板上方，仅决策时可交互。
- **HintPopover**: GTO 提示浮层，展示行动频率分布柱状图、EV 估算值、近似 GTO 说明。
- **FrequencyBar**: 行动频率分布可视化条形图，用于提示和复盘中显示 fold/call/raise 比例。

### Session 管理组件
- **SessionConfigModal**: 新建 session 配置弹窗，包含 BOT 数量选择、逐个 BOT 难度配置、盲注大小设置。
- **SessionControls**: Session 控制栏（暂停/继续/结束按钮），嵌入游戏页面顶部。
- **SessionSummaryModal**: Session 结束小结弹窗，展示本次手数、盈亏、关键偏差回顾。

### 复盘组件
- **HandList**: 牌局历史列表组件，支持虚拟滚动，每行显示摘要信息。
- **HandListFilter**: 历史筛选器组件，提供时间范围、结果、位置等筛选维度。
- **ReplayViewer**: 手牌回放主容器，整合牌桌状态重现和步进控制。
- **ReplayControls**: 回放控制栏，包含前进/后退/跳转按钮和键盘快捷键支持。
- **StreetTimeline**: 街进度时间轴，显示 Preflop→Flop→Turn→River 阶段标签，可点击跳转，偏差点用彩色圆点标注。
- **DeviationMarker**: 偏差标记组件，显示偏差等级（轻微/中等/严重）图标和颜色编码。
- **DeviationDetail**: 偏差详情面板（侧边抽屉或内联展开），显示实际行动 vs GTO 建议、频率对比、EV 损失。
- **ActionComparison**: 行动对比组件，并列展示用户实际行动和 GTO 建议行动的频率分布。

### 统计组件
- **StatsSummaryCards**: 统计概览卡片组（总手数、胜率、总盈亏），顶部横排布局。
- **ProfitChart**: 盈亏曲线折线图组件，支持 hover Tooltip 和可点击数据点。
- **KeyMetricsPanel**: 关键指标面板，展示 VPIP/PFR/3Bet%/WTSD% 等数值。
- **DeviationRanking**: GTO 偏差 TOP5 排行组件，显示最常见偏差类型和频次。
- **PositionBreakdown**: 位置盈亏分布柱状图组件，按 UTG/HJ/CO/BTN/SB/BB 展示。
- **TimeRangeFilter**: 时间/手数范围筛选器（最近 100 手/500 手/全部），用于统计页面顶部。

### 通用 UI 组件
- **Toast**: 全局 Toast 通知组件，用于错误提示和操作反馈。
- **Modal**: 通用模态弹窗容器，用于 Session 配置和小结等场景。
- **LoadingSpinner**: 加载旋转指示器，用于 CFR 计算等异步操作。
- **SkeletonLoader**: 骨架屏加载占位组件，用于页面初始数据加载。
- **NavSidebar**: 侧边导航栏，包含页面入口（首页/游戏/历史/统计）和当前 session 状态。
- **EmptyState**: 空状态提示组件（如无历史牌局时显示引导开始游戏）。
