## Market Overview

德州扑克GTO训练工具市场正处于快速增长期。全球在线扑克市场规模在2025年约42.4亿美元，预计2030年达114亿美元。GTO训练工具作为细分市场，受益于以下趋势：

1. **GTO学习需求爆发**：随着在线扑克竞争加剧，中级玩家对GTO策略学习的需求持续增长
2. **工具化趋势**：GTO Wizard等平台已与WPN、WPT Global等主流扑克平台合作，训练工具正成为标配
3. **定价空间**：主流GTO训练器月费$35-$129，存在免费/低价切入点的市场机会
4. **浏览器端技术成熟**：wasm-postflop已证明浏览器端CFR求解器的可行性（比桌面版慢约2x，精度与PioSOLVER相当）

**GTO Idiot的市场定位**：免费/开源的纯浏览器端GTO练习器，主打"实战对练+复盘对比"，与现有工具形成差异化——现有竞品多为"查询型"（输入局面→查GTO解），而GTO Idiot是"沉浸式练习型"（打完整牌局→赛后对比GTO偏差）。

### 竞争差异化分析

**GTO Idiot的核心差异点：**
1. **完整牌局对练** — 不是单个决策点训练，而是连续完整牌局（类似真实牌局体验）
2. **免费+本地运行** — 无需订阅，数据不离开浏览器（隐私友好）
3. **BOT难度分级** — 鱼/常规/GTO三档，模拟真实牌桌环境
4. **系统性复盘** — 不仅标记单个偏差，还提供统计总览和偏差模式分析
5. **零安装** — 纯浏览器应用，即开即用

## Feasibility

### 技术可行性评估

#### 1. 牌局引擎 — **高可行性** ✅
- Texas Hold'em牌局逻辑成熟，开源实现丰富
- 6-max现金桌规则明确，状态机实现直接
- React + TypeScript技术栈完全胜任

#### 2. BOT AI系统 — **中高可行性** ✅
- **鱼级BOT**：随机/松散策略，实现简单
- **常规级BOT**：基于范围表+简单规则，实现中等
- **GTO级BOT**：需要CFR近似，是主要技术挑战

#### 3. GTO计算引擎 — **中等可行性** ⚠️（MVP核心风险）

**翻前GTO**：
- 使用预计算的翻前范围表（静态数据），完全可行
- 6-max各位置的open/3bet/4bet范围已有大量公开数据
- 存储量小（~169个起手牌组合 × 6个位置 × 若干场景）

**翻后GTO**（主要挑战）：
- wasm-postflop已证明浏览器端CFR求解可行，但：
  - 完整博弈树巨大（需要抽象/简化）
  - 收敛到可用精度需要时间（秒级到分钟级）
  - 内存占用可能显著（数百MB）
- **MVP方案**：简化博弈树（限制下注尺度为33%/66%/100% pot）+ Discounted CFR + WebAssembly
- **预期性能**：简化树下可达亚秒级响应；完整精度需要妥协

**替代方案考量**：
- 方案A：实时CFR计算（简化树） — 灵活但性能风险
- 方案B：预计算翻后策略表 — 快速响应但存储量大、覆盖有限
- **推荐**：MVP采用翻前范围表 + 翻后简化CFR（方案A），并预留方案B作为降级选项

#### 4. 数据存储 — **高可行性** ✅
- IndexedDB完全满足本地牌局历史存储需求
- 单手牌数据量小（~1-2KB JSON），数千手牌存储无压力
- 浏览器兼容性优秀

#### 5. 复盘系统 — **高可行性** ✅
- 手牌回放本质是序列化数据的可视化，技术简单
- GTO偏差标记依赖GTO引擎的输出对比，与GTO计算模块耦合
- 统计面板是标准的数据聚合+图表展示

#### 6. UI/UX — **高可行性** ✅
- React + Tailwind CSS成熟方案
- 扑克桌面UI有大量开源参考
- 需要：牌桌渲染、筹码动画、行动面板、复盘时间线

## Key Insights

1. **市场缺口明确**：现有GTO工具以"查询/浏览"为主（GTO Wizard、PioSOLVER），缺少"完整牌局对练+自动复盘"的一体化免费工具。GTO Idiot填补了"练习→对比→改进"闭环中的实战模拟环节。

2. **翻后GTO是技术制高点也是最大风险**：浏览器端实时CFR已被wasm-postflop验证可行，但需要简化博弈树和使用WebAssembly。MVP应优先保证翻前GTO精度，翻后采用简化方案（3种下注尺度），并明确标注"近似GTO"而非"精确GTO"。

3. **BOT难度分级是核心差异化**：竞品要么只提供GTO对手，要么只提供随机对手。三档难度（鱼/常规/GTO）能让不同水平的玩家都找到合适的练习节奏，也模拟了真实牌桌的混合对手环境。

4. **复盘偏差分析是留存关键**：用户打完牌局后看到"你在CO位3bet频率比GTO低15%"这类具体反馈，能形成"练习→发现问题→针对练习"的正向循环。这是与纯娱乐型扑克应用的核心区分。

5. **纯浏览器端是双刃剑**：优势是零门槛（无需安装、无需账号、隐私安全），劣势是计算能力受限和数据不可跨设备同步。MVP阶段这是正确选择，后续可考虑可选的云端同步。

6. **预计算范围表数据是可获取的**：6-max翻前GTO范围在扑克社区已被广泛计算和发布，可作为初始数据源。翻后策略需要自行计算或简化近似。

7. **命名和品牌有记忆点**："GTO Idiot"自嘲式命名有趣味性，降低了GTO学习的心理门槛，暗示"即使是'笨蛋'也能通过练习掌握GTO"，利于社区传播。
