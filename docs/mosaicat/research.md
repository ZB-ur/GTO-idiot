## Market Overview

德州扑克GTO训练工具市场正处于高速增长期，受到线上扑克回暖和AI技术普及的双重驱动。市场主要分为三个层次：

1. **专业求解器**（PioSOLVER、GTO+、Simple Postflop）— 面向高级玩家和教练，价格$75-$475，桌面端，无训练模式
2. **云端训练平台**（GTO Wizard、Deepsolver、Lucid Poker）— 浏览器/移动端，订阅制$35-206/月，提供练习+复盘
3. **AI对战工具**（PokerSnowie）— 基于神经网络，$99-230/年，桌面端

**核心机会**：市场中**不存在免费的、浏览器端的、集"对战+复盘+GTO对比"于一体的六人桌训练工具**。GTO Wizard最接近但起步$35/月，且面向偏高阶用户。中级玩家面临"想练GTO但工具太贵或太复杂"的痛点。

## Feasibility

### 技术可行性：**高**

**Preflop GTO数据**
- 169种起手牌 × 6个位置 × ~10种常见场景（open/3bet/4bet等）≈ 10,140条目
- 存储需求：100KB - 2MB（JSON压缩后），完全可在浏览器内存中运行
- 数据来源：可参考公开的"Implementable GTO Charts"（将混合策略简化为0/50/100%频率）

**Postflop GTO数据**
- 完整解：数百GB到TB级别 — 不可能在浏览器中
- 简化方案：将22,100种翻牌抽象为~1,755个战略等价子集
  - 覆盖前200个最常见翻牌 + 常见下注线路：5-20MB
  - 全量1,755翻牌抽象：20-100MB
- MVP推荐：覆盖最常见场景的简化表（~10-15MB），按需懒加载

**BOT AI实现**
- **查表Bot（MVP推荐）**：预计算策略表 → 查找动作 → 按混合策略频率随机选择。实现简单（数百行代码），运行极快
- BOT风格差异化：在GTO基础上添加偏差参数（如Fish增加跟注频率、减少加注频率）
- 参考开源项目：pokersolver（JS手牌评估）、wasm-postflop（WASM求解参考）

**前端技术栈**
- React + TypeScript + Tailwind：成熟方案，完全满足需求
- localStorage/IndexedDB：存储牌局历史足够（每手牌~1-2KB，1000手仅1-2MB）
- 无需后端：所有逻辑前端完成，降低运维成本

### 业务可行性：**中高**

- **差异化明确**：免费 + 浏览器端 + 对战+复盘一体化 → 市场空白
- **获客路径**：扑克社区（2+2论坛、Reddit r/poker）、YouTube扑克教学频道
- **变现潜力**：免费MVP引流 → 高级GTO数据包/详细分析报告付费 → 广告（谨慎）
- **风险因素**：GTO数据精度可能被专业玩家质疑；需持续更新策略表

### 关键技术决策

| 决策点 | 推荐方案 | 理由 |
|---|---|---|
| GTO数据格式 | 分层JSON（preflop轻量 + postflop按需加载） | 平衡首次加载速度和覆盖面 |
| 手牌评估 | 查表法（预计算所有7462种手牌等级） | 前端性能要求高，查表最快 |
| BOT决策引擎 | GTO查表 + 风格偏差系数 | 简单可靠，风格差异化直观 |
| 复盘对比 | 玩家动作 vs GTO表推荐动作 → 颜色编码 | 直观易懂，核心价值体现 |
| 数据持久化 | IndexedDB（牌局历史）+ localStorage（设置） | IndexedDB支持结构化查询，适合牌局数据 |

## Key Insights

1. **市场定位精准**：免费浏览器端GTO训练器在$35-206/月的GTO Wizard和无训练功能的免费求解器之间存在明确空白。"GTO Idiot"的自嘲式命名降低了中级玩家的心理门槛，暗示"每个人都是GTO白痴，来这里练习"

2. **简化GTO比完整GTO更有训练价值**：研究表明中级玩家无法执行混合策略的精确频率。将GTO策略简化为"可执行版本"（Implementable GTO）反而是优势而非劣势。MVP的简化GTO表应定位为特性而非局限

3. **BOT风格多样化是核心体验差异化**：GTO Wizard仅提供对GTO对手的对战，而真实牌桌有各种风格。提供TAG/LAG/Fish/Nit/Maniac五种BOT让练习更贴近实战，复盘时对比"你 vs GTO vs 你的对手风格"三维分析是独特价值

4. **Preflop数据充足且公开可用**：6-max Preflop GTO范围有大量公开资源（PokerCoaching公开的GTO图表、Upswing的免费范围等），MVP的Preflop数据获取无障碍。Postflop是难点，需要从开源WASM Postflop或公开研究中获取简化数据

5. **技术栈完全可行，核心风险在GTO数据质量**：React+TS+Tailwind前端栈无任何技术障碍。真正的挑战是构建足够准确又足够小的GTO策略表。建议MVP先做精Preflop（准确度高），Postflop提供常见场景覆盖（标注"简化版"），后续逐步扩展

6. **复盘功能是留存关键**：竞品分析显示，纯对战工具留存低，带复盘分析的工具留存高。GTO偏离度的可视化（颜色编码热力图 + EV损失量化）是用户持续回访的核心驱动力
